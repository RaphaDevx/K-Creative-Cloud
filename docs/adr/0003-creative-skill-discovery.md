# ADR 0003 — Shared creative skill discovery

2026-10-13. create is output router; create-reel/create-music use k-creative-cloud as common tool/project contract. scripts/creative_tools.py does read-only kind-filtered discovery of installed adapter paths and reviewed integration manifests. Presence is not runtime readiness; every selected engine requires task probe. No manifest commands run, no automatic installs or skill rewrites. Native Rust project authority is preserved.

Screen-recording implementation belongs to packages/screen-recording, K-AI old path remains launcher. TTS model path becomes repo-relative with environment override. Simple render workflows retain FFmpeg/Pillow; advanced photo/vector/timeline/music/CAD remain GIMP/Inkscape/Kdenlive/LMMS/FreeCAD/Blender. ArtCraft manifests candidate only pending format/automation/fidelity tests; whole-suite replacement not justified by upstream parity/clean-room claims alone.
