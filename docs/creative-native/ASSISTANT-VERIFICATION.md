## Limits and remaining release work

This is an integrated local editing engine with interchangeable planners, not a pure Rust/Swift GUI, arbitrary full-program automation or a complete brand campaign. New providers need compatible protocol/model support. Arbitrary mesh editing, arbitrary raster retouching and real hardware microphone/target-platform permission behavior remain beyond the verified primitive/layer flows. Fonts are fallback stacks, not installed/licensed font files. Brand fundamentals remain draft until audience/positioning/assets are confirmed.

The dedicated project skill is validated and included in planner instructions; global K-AI catalog promotion remains its normal separate review step. Existing unrelated desktop/macOS/CAD work is preserved. No new DMG/AppImage release or external account publication is performed. Legacy repository-wide security-gate failures from the previous integration are not claimed resolved by this change.
