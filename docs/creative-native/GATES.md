# Acceptance gates
- Rust: typed operations, validation, disk reload, persisted undo/redo and split semantics pass cargo tests.
- UI: three editor modes, project creation, edit commands, save/reload, genuine exports and embedded terminal work in browser.
- Media: fixture-based PNG, WAV and MP4 exports have independently verified dimensions/durations; invalid input fails.
- Bridge: HTTP and MCP action parity, path confinement, jobs and errors tested.
- Integration: existing studio routes remain reachable; browser console has no uncaught errors.
- Follow-up inventory: provider AI-video/image, full native DAW engines, Blender timeline renders and SSH workers must be reported honestly if not delivered in this wave.
- Desktop: actual packaged Linux startup, token enforcement, zero npm audit findings; native Mac DMG signing/notarization and published R2 ZIP/manifest remain mandatory release gates.
- LLM: interactive PTY with Ctrl-C, scoped Codex/Claude MCP registration; account onboarding stays with user.
- AI assets: optional local ComfyUI connector with truthful unavailable state; no default model-specific AI video workflow promised.
