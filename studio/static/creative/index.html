Verfügbarkeit wird geprüft. Konto- und Modellzugriff werden beim Auftrag bestätigt. Lokale Befehle senden keine Daten an einen KI-Anbieter.
Anbieter einrichtenSchlüssel bleiben im Arbeitsspeicher bis zum Beenden der App. Dein Modell muss für Skizzen Bilder verstehen.
Was kann ich hier tun?

Lokale 3D-Befehle erstellen einfache Formen, zum Beispiel «Erstelle eine Kugel». Für Logos aus Skizzen, freie Änderungen und Erklärungen wähle einen KI-Anbieter; Skizzen benötigen ein Modell mit Bildverständnis. Eine installierte CLI wird erst beim Auftrag auf Konto- und Modellzugriff geprüft.

Wähle für Änderungen zuerst dein Objekt aus. Antworte auf Rückfragen im selben Eingabefeld. «Rückgängig» nimmt die letzte Projektänderung zurück; «Neuer Dialog» leert nur dieses Gespräch und seine Referenz.

Beschreibe dein Vorhaben. Zum Beispiel: «Erstelle eine Kugel», «Erstelle ein Logo aus dieser Skizze» oder «Wie nutze ich K-Photo?»
