00 — Design Principles
Hard Constraints
Strikte Regeln — an shadcn/ui, Vercel Geist, Linear.app orientiert
01 · BORDERS
1px Hairlines only
Ausschließlich 1px solid var(--border). Keine dicken Rahmen. Keine farbigen Borders außer bei aktivem Fokus-State.
02 · SHADOWS
Kein Glow, kein Drop
Maximal box-shadow: 0 0 0 3px accent/12% nur auf Fokus-Inputs. Keine weichen Schatten, keine Neon-Glows.
03 · COLOR 90/10
Farbe ist Funktion
90% des UI sind monochrom neutral. Kyanit / Sage / Rust erscheinen ausschließlich als funktionale Status-Signale — niemals als Kartenhintergrund.
04 · TYPOGRAPHY
Inter · Mono für Daten
Display: Space Grotesk, -0.025em. Body: Inter. Alle Zahlen, IDs, Hex-Werte: JetBrains Mono.
